# COVID-19 Chest X-Ray Classification with Deep Learning

## About the project
This project explores how deep learning can be used to classify chest X-ray images into two categories: COVID-19 and Normal. I built and trained a CNN model using TensorFlow and Keras, then reviewed its predictions and performance.

## What I learned
Through this project, I practiced preparing image data, training a deep learning model, and evaluating its results using a confusion matrix and classification metrics.

## Tools used
Python, TensorFlow, Keras, Matplotlib, Seaborn, and scikit-learn.

## Important note
This is an educational project, not a medical diagnostic tool.
